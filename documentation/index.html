SVG-Like Program For JS13k


Mini-SVG is a simple function developed to draw little SVG-like drawings through the html canvas 2d context (ctx). It takes in 3 parameters like so: svg("svg-data",[xPos,yPos,xScale,yScale],[palette])
  • svg-data is a string that contains all the instructions for the drawing program. Every command and argument must be separated by a space.
  • xPos & yPos is where your drawing is being drawn
  • xScale & yScale is the scale of your drawing
  • palette (optional) is an array of colors used to dynamically change the look of an svg without storing the exact same svg in different colors.

To use the program you must put the following function somewhere in your code:

function svg(b,d,e=[]){ctx.save(),ctx.translate(d[0],d[1]),ctx.scale(d[2],d[3]);for(var c=b.split(" ");0<c.length;){var f=c[0],g=new Path2D,h="00";if("p"==f){let a=c.join(" ");g=new Path2D(a.slice(2,a.indexOf(":"))),h=(c=a.slice(a.indexOf(":")+1).trim().split(" "))[0]}else"w"==f?ctx.lineWidth=c[1]:"g"==f?ctx.globalAlpha=c[1]:"s"==f?ctx.shadowBlur=c[1]*Math.abs(d[2]):"c"==f?("$"==c[1][0]&&(c[1]=e[c[1].slice(1)]),"1"==c[2][0]&&(ctx.fillStyle=c[1]),"1"==c[2][1]&&(ctx.strokeStyle=c[1]),"1"==c[2][2]&&(ctx.shadowColor=c[1]),c.shift()):"a"==f?(g.arc(c[1],c[2],c[3],.01745*c[4],.01745*c[5]),h=c[6]):"r"==f?(g.rect(c[1],c[2],c[3],c[4]),h=c[5]):"<"==f?ctx.save():">"==f?ctx.restore():"t"==f?ctx.translate(c[1],c[2]):"q"==f&&ctx.rotate(.01745*c[1]);c.shift(),"1"==h[0]&&ctx.fill(g),"1"==h[1]&&ctx.stroke(g)}ctx.restore()}

Many instructions rely on a 2-bit string to determine if a shape should be filled, stroked, or both.
Flag Fill Shape Stroke Shape
10 Yes No
01 No Yes
11 Yes Yes
svg-data has 11 possible instructions:
  1. p is equivalent to new Path2D(svg-data), its syntax looks like: p svg-data... :flags
    • svg-data consists of SVG path data, a new path is created from that description.
    • The path data must end with a colon : immediately followed by the 2-bit fill/stroke flags.
    • Example: "p m 0 0 l 100 0 l 50 100 z:10" (This draws a filled triangle).

  2. a is equivalent to ctx.arc(), its syntax looks like: a x y radius startAngle endAngle flags
    • startAngle & endAngle are in degrees
    • flags is the 2-bit string for fill/stroke
    • Example: "a 50 50 10 0 360 11" (This draws a filled and outlined circle with a 10px radius).

  3. r is equivalent to ctx.rect(), its syntax look like: r x y width height flags
    • flags is the 2-bit string for fill/stroke
    • Example: "r 0 0 100 10 1" (This draws a filled rectangle that is 100px wide and 10px tall).

  4. c lets you set the color, its syntax looks like: c color fill_stroke_shadow
    • fill_stroke_shadow is a 3-bit string indicating whether to set ctx.fillStyle, ctx.strokeStyle, and ctx.shadowColor respectively.
      • Flag Fill Stroke Shadow
      100 Yes No No
      010 No Yes No
      111 Yes Yes Yes
    • color can be any html eligible format #hex, rgba(), etc.
    • Palette Lookup: If color starts with $, it will grab the color from the palette array at that index. This lets you dynamically change the look of an svg without storing the exact same svg in different colors!
    • Example: "c $0 111" (This uses the first color in your palette array to set the fill, stroke, and shadow).

  5. w is equivalent to ctx.lineWidth, its syntax look like: w lineWidth
    • lineWidth may need to be adjusted depending on the scale you set in the svg() function
    • Example: "w 10" (This makes your strokes 10px thick).

  6. g is equivalent to ctx.globalAlpha, its syntax look like: g alpha
    • Example: "g 0.8" (This sets the transparency to 80%).

  7. s is equivalent to ctx.shadowBlur, its syntax look like: s shadowBlur
    • Example: "s 30" (This creates a shadow with a 30px blur).

  8. t is equivalent to ctx.translate(), its syntax look like: t x y
    • Example: "t 100 10" (This moves the drawing context 100px right and 10px down).

  9. q is equivalent to ctx.rotate(), its syntax look like: q angle
    • angle is in degrees
    • Example: "q 45" (This rotates the drawing context by 45 degrees).

  10. < is equivalent to ctx.save() (This saves the current canvas state so you can return to it later).
  11. > is equivalent to ctx.restore() (This restores the last saved canvas state).
